# 欄位規格（35 欄，順序固定）

版面：第 1 欄＝編號、第 2 欄＝材料名、第 3 欄＝SMILES、第 4–29 欄＝26 項 ML 特徵、第 30 欄＝PCE（target）、第 31–35 欄＝出處與狀態。

標頭列（第1列）底色分類（灰/橘/綠/藍/藍灰/黃/粉紫）見 SKILL.md「欄位標頭底色」表；此處只列每欄的資料內容規則。

## 1. 編號
格式：`{ref編號}-{分子名}({條件註記})`。例：`48-1.68eV,NiOx/MeO-4PADBC(組成確認)`、`52-Me-PhpPACz(champion)`、`25-MeO-2PACz(共蒸鍍MAPbI3)`。黑格列只寫 ref 編號。同論文多列時，條件註記必須能區分（champion/control/bandgap/基板）。

## 2. SAM/HTL材料名稱
論文使用的分子簡稱。複合寫法：`NiOx+Me-4PACz`、`2PACz+MeO-2PACz(1:1)`、`Me-4PACz+ABT(7.5:1)`。

## 3. smile（SMILES）
- 全部須通過 RDKit `MolFromSmiles` 解析。
- 來源優先序：論文明示結構式/IUPAC 名（確定性推導→**白**）＞名稱推測（接位/鏈長/取代位有歧義→**紅**＋Notes 說明查哪張結構圖）。
- 論文完全未給結構（unnamed SAM）→ 留空。
- 氘代等同位素標記照寫（如 `[2H]`）。

## 4. NiO2
0/1：是否使用 NiOx 底層。SAM 直接在 ITO/FTO 上＝0。

## 5–11. 溶劑欄（ethanol, toluene, IPA, THF, chlorobenzene, 2-Methoxyethanol, CH2CL2）
- 0/1：SAM 沉積溶劑。已確認未使用＝0，論文可讀但查不到＝留空。
- **溶劑無對應欄位**（DMF、DMSO、methanol、chloroform、acetonitrile…）→ 七欄**全填 0**＋Notes 註記實際溶劑（例：`溶劑DMF(無欄位,全0)`）。
- 混合溶劑：有欄位者填 1，無欄位成分在 Notes 註記（例 ethanol:CHCl₃=1:1 → ethanol=1＋註記）。
- 由間接敘述推論的溶劑（如 UV-vis 段落提及）→ 填 1 但**標紅**。

## 12. concentration(mg/ml)
- 論文給 mg/mL → 直接抄（白）。
- 論文給 mM → `mM × MW / 1000`，MW 用 RDKit 由 SMILES 算（確定性計算→**白**；但若 SMILES 本身是紅，換算值繼承紅）。
- 混合 SAM：填總濃度並在 Notes 寫拆分（例 `4.5+0.6mg/mL共摻`）。
- 給範圍無單值（"0.3–3 不敏感"）→ 留空＋Notes。
- 浸泡法（dipping）照填溶液濃度。

## 13. wash
0/1：SAM 成膜後是否用溶劑沖洗（rinse）去除未鍵結分子。判定優先序：
1. 元件製程段（Methods/device fabrication）明示沖洗 → 1（白）。
2. 製程完整描述但無沖洗步驟 → 0，標紅＋Notes `wash=0未記載推論`（「沒寫」≠「確認沒做」）。
3. **dipping/浸泡法且製程段未明示** → 1，標紅（浸泡後沖洗為標準操作，B 級經驗法則）。
4. **表徵段間接證據**（洗滌實驗、"after the washing procedure" 等出現在圖說/表徵討論）→ 可推 1 但標紅＋Notes 寫明出處（例 `wash=1由Fig.2c洗滌實驗間接推論`）。
5. 規則衝突時，製程段明文 > 一切間接證據。

## 14. E（能階差，eV）
**定義：E = E_HOMO(SAM) − E_VBM(perovskite)，帶正負號。**
- 正＝SAM HOMO 比鈣鈦礦 VBM 淺（利於取電洞）；負＝更深。合理範圍約 −0.6 ~ +0.9。**絕不取絕對值**（原始訓練集含負值，min≈−0.16）。
- **只能用「同一篇論文、同一種方法」的兩個值相減**。方法優先序：UPS/PESA（實測）≫ CV。**嚴禁 CV 與 UPS 混減**（系統差 0.3–0.6 eV），嚴禁 DFT 計算值當實測。
- UPS 換算式：`IP = 21.22 − E_cutoff + E_onset`（He I）。讀圖後務必用此式與圖上其他標註交叉驗證。
- 論文只有 SAM HOMO 沒有 pvk VBM（或反之）→ **留空**，在「E補值紀錄」登記已知的那一半，等使用者核可跨文獻配對才可補（補了標紅＋雙 DOI）。
- 來源是文字（"ΔEVBM = 0.26 eV"）→ 白；來源是能階圖上印的數字 → 紅（讀圖）；經設計假設/中點反推 → 紅（推算）。
- 同分子不同文獻 HOMO 可差 0.3–0.6 eV（量測系統、基板、覆蓋度），這是 E 不能跨文獻直接搬的原因。
- **作者背書的引用值（"data from ref. XX"）**：若論文**自己**把引用值放進能階圖或比較句（即 offset 是論文主張的），該 E 可用——配對由領域專家＋同儕審查背書，可信度介於同文自洽與自行跨文獻之間。條件與處置：
  1. 引用值與本文實測值須為**同型方法**（UPS 對 UPS）；引用源是 CV 而本文是 UPS → 不可用。
  2. **顏色依取值方式決定，與「是否引用」無關**：值從論文文字抄錄 → 白（配對責任在作者，非 AI 流程誤差）；值從能階圖上讀 → 紅（讀圖）＋Notes。不論顏色，被引用的 ref/DOI 一律登記在「E補值紀錄」。
  3. 行有餘力時開被引論文快速核對該值與方法（一次查詢），並在紀錄註明已核對。
  4. 若**兩個值都**是引用（論文自己什麼都沒量），僅在論文明確以該圖為能階對齊依據時可用，同樣標紅；否則留空。
  5. 我們**自行**從 ref XX 抓值與本文值相減（論文沒做這個比較）→ 屬自行跨文獻，未經使用者核可不得填。

## 15–17. Cs, FA, MA（A-site 陽離子比）
- 正規化：**三者加總＝1**。巢狀式展開，例 Cs0.05(FA0.95MA0.05)0.95 → Cs=0.05, FA=0.9025, MA=0.0475。
- 無欄位陽離子（Rb、K、DMA、GA…）→ 不計入但 Notes 註記（此時加總<1 允許，需說明）。
- 兩溶液體積比混合（FAPbI₃:MAPbBr₃=3:2）→ 可推算但**標紅**＋註記推算式。
- 原文組成式疑似筆誤（加總>1 等）→ 按化學慣例解讀＋**標紅**＋Notes 寫明原文寫法。

## 18–19. Pb, Sn（B-site）
加總＝1。純 Pb＝1/0。Pb-Sn 合金按莫耳比。

## 20–22. I, Br, CL（X-site 鹵素比）
加總＝1。例 Pb(I0.76Br0.24)₃ → I=0.76, Br=0.24, CL=0。PbI2.7Br0.3 → I=0.9, Br=0.1。

## 23–29. ETL 欄（C60, BCP, PC60BM, PCBM, PC61BM, PEAI, ALD-SnO2）
- 0/1：元件堆疊是否使用該材料。**依論文自己的命名**填對應欄（PCBM vs PC61BM 是不同欄——即使化學上同物，跟著原文寫法走）。
- **元件堆疊已完整列舉時，未提及的 ETL 欄一律填 0**（不要留空）。
- PEAI/PEABr 等鈍化層：作為 pvk/ETL 界面處理＝1；摻入前驅液或縮寫歧義（PI）→ 填 1 標紅＋註記。
- 無欄位的鈍化/緩衝材（TEACl、PMMA、LiF、MgF₂…）→ 不影響 0/1 欄，Notes 註記。

## 30. PCE（%）
- 取該列條件的 champion 反掃值（或論文標示的代表值）；穩態(SPO)/認證值在 Notes 註記。
- 正文只寫「超過 X%」→ 填 X 標紅＋Notes `PCE:正文僅'超過X%',下限估計`。
- 摘要可得、全文不可讀 → 照填（黑格列的 PCE 允許填白值）。

## 31. Reference_DOI
- 填 DOI 本體（10.xxxx/...）。**寫入前必驗證**：doi.org 解析後的頁面標題須與論文相符（曾發生 DOI 錯置到另一篇論文）。

## 32–33. Ref_author / Ref_journal
第一作者 et al. / 期刊名。

## 34. Data_status
格式＝`{基底}；{特殊註記}；缺:{清單}`
- 基底：`完整(全文+SI)`、`完整(全文)`、`完整(全文,OA)`、`無法讀取(僅摘要,原因)`（原因如：付費牆、VPN無此刊權限、被Cloudflare阻擋）。
- **「缺:」清單必須與該列實際空格完全一致**（含 E）。溶劑七欄全空縮寫為「溶劑」，組成八欄全空縮寫為「組成」，concentration 寫「濃度」。
- 寫「完整」卻有空格＝違規。每批寫入後跑程式稽核一次。

## 35. Notes
見 SKILL.md「Notes 欄規則」。白格列留空。
